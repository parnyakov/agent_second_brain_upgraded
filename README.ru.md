# Agent Second Brain

Персональный AI-агент в Telegram с памятью в Obsidian. Вы пишете или
надиктовываете мысли, задачи и заметки, а агент раскладывает их по файлам,
помнит контекст, напоминает о важном и каждый вечер присылает сводку дня.

## Начать здесь

**Что получится.** На вашем сервере круглосуточно работает Telegram-бот.
За ним стоит агент на подписке ChatGPT (Codex) или Claude (Claude Code),
а память лежит в вашем приватном репозитории GitHub.

**Что приготовить заранее** (около 30 минут, всё бесплатно, кроме подписки и сервера):

| Что | Где | Зачем |
|---|---|---|
| Аккаунт GitHub | github.com | хранить приватную копию памяти (программа скачивается без входа) |
| Telegram-бот и его токен | @BotFather, команда `/newbot` | через него вы говорите с агентом |
| Ваш числовой Telegram ID | @userinfobot | бот отвечает только вам |
| Ключ Deepgram | console.deepgram.com | расшифровка голосовых |
| Подписка ChatGPT Plus/Pro **или** Claude Pro/Max | chatgpt.com или claude.ai | «мозг» агента |
| Сервер (VPS) Ubuntu 24.04: 2 vCPU, 4 ГБ RAM, 40 ГБ диска, в Европе (не в России) | любой VPS-провайдер, например HOSTKEY, Нидерланды; пошагово в разделе 3 инструкции | здесь работает агент |

**Во время установки понадобятся компьютер и телефон:** установщик три раза
попросит открыть ссылку и подтвердить вход. Это вход в GitHub (шаг 5, код на
github.com/login/device), затем «Start» в вашем боте, затем вход в ChatGPT или
Claude (ссылка и код). Без этих действий установка не завершится, и это
нормально.

**Порядок установки** (подробно, с разбором ошибок: [docs/install.ru.md](docs/install.ru.md)):

1. Арендуйте сервер и войдите по SSH как `root` (разделы 3–4).
2. Создайте обычного пользователя и войдите им (раздел 5).
3. Выполните одну стартовую команду (раздел 6) и отвечайте на вопросы
   установщика (раздел 7). Займёт 15–25 минут.

Стартовая команда целиком, ничего в ней менять не нужно:

```bash
sudo apt-get update && sudo apt-get install -y git curl && git clone https://github.com/parnyakov/agent_second_brain_upgraded.git ~/projects/agent-second-brain && bash ~/projects/agent-second-brain/bootstrap.sh
```

Сначала она спросит пароль пользователя сервера (для `sudo`). Этот
репозиторий публичный: приглашение, форк и вход в GitHub для скачивания не
нужны. Вход в GitHub установщик попросит позже, на шаге 5, чтобы создать
вашу приватную память.

**Как понять, что всё готово.** В конце установщик пишет
`[OK] Агент ответил на проверочный вопрос` и `[OK] Установка завершена`, а бот
присылает в Telegram «Установка завершена». Если вместо этого `[X] ...`,
выполните строки «Что сделать» и запустите установку снова:

```bash
bash ~/projects/agent-second-brain/bootstrap.sh
```

Повторный запуск безопасен: введённые токены и ваша память сохраняются,
готовые шаги пропускаются. Закрыли терминал или пропал интернет: войдите
заново и выполните ту же команду.

**Дальше в Telegram.** Отправьте боту `/onboarding`. Агент познакомится с
вами: профиль, проекты, цели, стиль работы, какими сервисами пользуетесь и
как перенести старые заметки. Можно отвечать голосом, прерываться и
продолжать той же командой. Памятка о возможностях: `/help` и файл
`GUIDE.md` в памяти.

**Что не входит в установку.** Готовых подключений к Google Drive, Календарю,
Gmail, Notion и другим сервисам нет, мастера подключения тоже нет. Агент может
подсказать шаги, но настраивать их придётся отдельно и вручную (раздел 13).

## Что умеет

- Принимает текст, голосовые, фото, документы и пересланные сообщения.
- Отвечает как полноценный агент: ищет в заметках, правит файлы, выполняет
  команды на сервере.
- Ведёт задачи, заметки, проекты и каскад целей (3 года, год, месяц, неделя).
- Ставит напоминания и регулярные задачи: «каждый будний день в 9:00
  присылай план дня».
- Раз в день обрабатывает записи и присылает отчёт (автоматически в 21:00
  или по команде /process).
- Помнит важное между разговорами: память хранится в файлах, а не в чате.
- Перед публикациями, платежами, удалением данных, выдачей доступа и
  сообщениями третьим лицам всегда спрашивает подтверждение.

Подробная памятка для пользователя: [templates/vault/GUIDE.md](templates/vault/GUIDE.md).

## Как устроено

```
Telegram-бот
    │  текст, голос (расшифровка через Deepgram), фото, файлы
    ▼
Постоянная сессия агента (Codex или Claude Code)
    │  читает и пишет обычные Markdown-файлы
    ▼
Vault в формате Obsidian (заметки, задачи, цели, память)
    │  автоматическая синхронизация
    ▼
Приватный репозиторий GitHub (резервная копия памяти)
```

Расписания: ежедневная обработка и проверка здоровья работают через таймеры
systemd, а напоминания и регулярные задачи агент создаёт сам через скилл
`cron`.

## Два репозитория

| Репозиторий | Что в нём | Доступ |
|-------------|-----------|--------|
| Этот репозиторий (код) | Бот, агентные инструкции, скиллы, шаблоны. Личных данных нет | Публичный: установка и обновления скачивают его без входа. Форк не нужен |
| Ваш репозиторий памяти (vault, по умолчанию `dbrain-vault`) | Ваши заметки, задачи, цели, память агента | Отдельный репозиторий в вашем аккаунте GitHub. Создаётся при установке, всегда PRIVATE, доступ только у вас |

В репозитории кода папка `vault/` игнорируется, кроме общих инструкций
агента (`vault/.claude/`). Всё личное живёт только в вашем репозитории памяти.

## Приватность

- **Голосовые** отправляются на расшифровку в Deepgram.
- **Текст** (сообщения, расшифровки, нужные для ответа файлы) обрабатывает
  выбранный AI-провайдер (OpenAI для Codex или Anthropic для Claude Code).
- **Всё остальное** остаётся на вашем сервере и в вашем приватном
  репозитории памяти.
- Токены и ключи хранятся только в `.env` на сервере и не попадают в vault,
  Git и ответы.

## Команды

В Telegram:

| Команда | Что делает |
|---------|------------|
| /start | Приветствие и краткая справка |
| /help | Возможности и команды |
| /status | Что записано сегодня |
| /work | Что агент делает прямо сейчас (отвечает, даже когда он занят) |
| /resend | Прислать последний ответ ещё раз |
| /process | Обработать записи дня сейчас |
| /onboarding | Начать или продолжить знакомство |
| /new | Новый разговор (память в файлах сохраняется) |
| /compact | Сжать длинный разговор |
| /relogin | Пересоздать сессию, если после `dbrain login` бот всё ещё просит вход |

На сервере:

| Команда | Что делает |
|---------|------------|
| `dbrain status` | Состояние бота и агента |
| `dbrain doctor` | Проверка с подсказками |
| `dbrain logs` | Последние логи |
| `dbrain restart` | Перезапуск сервисов |
| `dbrain repair` | Сброс ошибок и перезапуск |
| `dbrain login` | Повторный вход в AI-провайдера |
| `dbrain onboarding` | Знакомство в терминале |
| `dbrain permissions` | Права агента: `status`, `max`, `standard` |

## Обновление

```bash
git -C ~/projects/agent-second-brain pull --ff-only && bash ~/projects/agent-second-brain/upgrade.sh
```

Обновление не трогает вашу память: vault живёт в отдельном репозитории.
