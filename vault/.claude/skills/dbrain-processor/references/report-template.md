# HTML-отчёт для Telegram

## КРИТИЧНО: формат

**Только сырой HTML. Никаких Markdown-обёрток.**

НЕПРАВИЛЬНО (блок кода):
```html
<b>Заголовок</b>
```

ПРАВИЛЬНО (сырой HTML):
<b>Заголовок</b>

Результат уходит прямо в Telegram с `parse_mode=HTML`. Бот оставляет только
разрешённые теги; если теги не сбалансированы, отчёт уйдёт плоским текстом
с видимыми `<b>`, поэтому проверяй закрытие.

## Разрешённые теги

<b> : жирный (заголовки разделов)
<i> : курсив (метаданные)
<u> : подчёркивание
<s> : зачёркивание
<code> : команды, пути
<pre> : блок моноширинного текста (редко)
<a href="url">текст</a> : ссылки

## ЗАПРЕЩЕНО

- Markdown: `**`, `##`, `- `, `*`, обратные кавычки, нумерация `1.`
- Блоки кода с тройными кавычками
- Таблицы (Telegram их не показывает)
- Теги `div`, `span`, `br`, `p`, `table`, `tr`, `td`, `strong`, `em`
- Неэкранированные `<`, `>`, `&` в тексте (`&lt;`, `&gt;`, `&amp;`)
- Вложенные одинаковые теги `<b><b>…</b></b>`
- Wiki-ссылки `[[…]]`: в Telegram пиши название заметки текстом

## Правила разделов

### Фокус (🎯)
Из `goals/3-weekly.md`. Если не найден: «Не задан, обновите goals/3-weekly.md».

### Заметки (📓)
Количество и список с эмодзи категории:
💡 idea, 🪞 reflection, 🎯 project, 📚 learning

### Задачи (✅)
Количество и список. Формат: `• Отправить черновик бюджета <i>(p2, пт 13.03)</i>`

### Проекты (📁)
Только если что-то изменилось в `projects/`.

### Люди (👤)
Только если в записях есть люди из словаря или новые важные имена.

### Загрузка (📅)
Открытые `- [ ]` со сроками на ближайшие 7 дней из `daily/` и
`projects/*/status.md`. Формат: `Пн: 4 | Вт: 2 | …`

### Внимание (⚠️)
Только если есть что показать: просроченные задачи, цели без движения 7+
дней, вопросы владельцу (неизвестный проект, неподтверждённый вывод),
незавершённый онбординг (не чаще раза в день).

### Связи (🔗)
Только если созданы новые.

### Приоритеты (⚡)
Открытые задачи, отсортированные по приоритету и сроку, первые три.

### Прогресс по целям (📈)
Цели года с активностью. Эмодзи: 🔴 0-25%, 🟡 26-50%, 🟢 51-75%, ✅ 76-100%.
Если процентов в файле целей нет, пиши «активна» или «без движения N дней».

### Здоровье vault (🩺), память (🧠), наблюдения (👁)
Только если есть данные или изменения.

## Отчёт об ошибке

📊 <b>Обработка за {DATE}</b>

❌ <b>Ошибка обработки</b>

<b>Причина:</b> {error_message}
<b>Файл:</b> <code>{file_path}</code>

<i>Попробуйте /process ещё раз</i>

## Пустой день

📊 <b>Обработка за {DATE}</b>

📭 <b>Нет записей для обработки</b>

Файл <code>daily/{date}.md</code> пуст.

<i>Отправляйте боту заметки в течение дня</i>

## Длина

Не больше 4096 символов. Если не помещается, сокращай по порядку: «Новые
связи», «Наблюдения», «Здоровье vault», затем оставь три цели в «Прогрессе».

## Проверка перед отправкой

1. Все теги закрыты.
2. Нет сырых `<` и `>` в тексте.
3. Нет Markdown и `[[…]]`.
4. Нет таблиц.
5. Длина меньше 4096.
6. Первая строка `📊 <b>Обработка за {DATE}</b>` (или `Статус за`).
