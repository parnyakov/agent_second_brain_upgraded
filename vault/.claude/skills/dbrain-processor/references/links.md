# Wiki-ссылки

## Зачем

Связи между заметками превращают vault в граф знаний: агент находит контекст,
а владелец видит связи в Obsidian.

## При сохранении заметки

### Шаг 1: найти связанные заметки

Поиск по `thoughts/`, `projects/`, `personal/`:

```
Grep "ключевое слово 1" in thoughts/**/*.md
Grep "ключевое слово 2" in projects/**/*.md
```

Что искать:
- основную тему заметки;
- сущности (люди, проекты, инструменты);
- термины предметной области.

### Шаг 2: проверить MOC

```
MOC/
├── MOC-ideas.md
├── MOC-projects.md
├── MOC-learnings.md
└── MOC-reflections.md
```

Если файла нет, создай его при первой заметке этой категории.

### Шаг 3: связать с целями

Прочитай годовой файл целей (`goals/1-yearly-YYYY.md` или `goals/1-yearly.md`)
и найди подходящую цель.

### Шаг 4: добавить ссылки с контекстом

Каждая ссылка объясняет, ПОЧЕМУ она есть.

**Во frontmatter (для анализа графа):**
```yaml
related:
  - "[[thoughts/ideas/2026-03-02-client-onboarding-checklist]]"
  - "[[goals/1-yearly#Проект А приносит стабильную выручку]]"
```

**В тексте:**
```markdown
Это развивает [[Чек-лист подключения клиента]], который обсуждали раньше.
```

**В разделе Related (с поясняющей фразой):**
```markdown
## Related
- [[thoughts/ideas/2026-03-02-client-onboarding-checklist|Чек-лист подключения]] — extends: добавляет шаг обучения
- [[projects/proekt-a/status|Проект А]] — context: возникло на планёрке проекта
- [[goals/1-yearly#Проект А приносит стабильную выручку]] — supports: цель года
```

### Типы связей

| Тип | Когда | Пример |
|-----|-------|--------|
| extends | Развивает другую идею | `— extends: добавляет шаг обучения` |
| context | Откуда идея | `— context: возникло на планёрке` |
| supports | Работает на цель | `— supports: цель квартала` |
| contradicts | Спорит с заметкой | `— contradicts: раньше решили иначе` |
| enables | Делает возможным | `— enables: автоматический отчёт` |
| requires | Зависимость | `— requires: доступ к календарю` |

### Шаг 5: обновить MOC

```markdown
# MOC: Идеи

## Недавние
- [[thoughts/ideas/2026-03-12-evening-report-shorter]] — короче вечерний отчёт

## По темам
### Проект А
- [[thoughts/ideas/2026-03-02-client-onboarding-checklist]]
```

### Шаг 6: обратные ссылки

В тесно связанную заметку добавь обратную ссылку на новую.

## Формат ссылок

```markdown
[[Название заметки]]                 # простая
[[Название заметки|Отображаемый текст]]  # с псевдонимом
[[папка/Название заметки]]           # с путём
[[Название заметки#Раздел]]          # на заголовок
```

### Ссылки на цели
```markdown
[[goals/1-yearly#Название цели]]
[[goals/3-weekly]] — ONE Big Thing
```

## Ссылки на проекты

| Тип | Формат | Пример |
|-----|--------|--------|
| Проект | `[[projects/{slug}/status\|Название]]` | `[[projects/proekt-a/status\|Проект А]]` |
| Человек | `[[{путь к карточке}\|Имя]]` | `[[projects/proekt-a/people/anna\|Анна]]` |

### Где ставить

**В daily (комментарием, исходную запись не меняя):**
```markdown
## 10:30 [voice]
Созвонились с Анной по бюджету Проекта А
<!-- связь: [[projects/proekt-a/status]] -->
```

**В заметках (Related с поясняющей фразой):**
```markdown
## Related
- [[projects/proekt-a/status|Проект А]] — context: обсуждение бюджета
```

**В задачах:**
```markdown
- [ ] Отправить черновик бюджета (due: 2026-03-13, p2) → [[projects/proekt-a/status|Проект А]]
```

## Раздел отчёта

```html
<b>🔗 Новые связи:</b>
• Чек-лист подключения ↔ Проект А
• Короче вечерний отчёт → цель года
```

В отчёте пиши названия заметок текстом: Telegram не показывает `[[ссылки]]`.

## Пример

Новая заметка: «Недельный обзор быстрее начинать с календаря»

1. **Поиск:** «обзор» → находится `thoughts/reflections/2026-02-20-weekly-review-takes-too-long`.
2. **MOC:** в `MOC-learnings.md` есть раздел «Планирование».
3. **Цели:** в годовых целях есть «Меньше авралов в работе отдела».
4. **Связи:**
   ```yaml
   related:
     - "[[thoughts/reflections/2026-02-20-weekly-review-takes-too-long]]"
     - "[[goals/1-yearly#Меньше авралов в работе отдела]]"
   ```
5. **MOC-learnings.md:**
   ```markdown
   ### Планирование
   - [[thoughts/learnings/2026-03-12-weekly-review-calendar-first]] — обзор с календаря
   ```
6. **Отчёт:** `• Обзор с календаря ↔ Обзор занимает слишком долго`

## Изолированные заметки

Заметка изолирована, если:
- на неё нет входящих ссылок;
- `related` пуст;
- её нет ни в одном MOC.

Покажи в отчёте, если такие появились:
```html
<b>⚠️ Заметки без связей:</b>
• thoughts/ideas/2026-03-12-some-note
```
