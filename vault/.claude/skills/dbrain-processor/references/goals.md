# Связь с целями

## Сначала всегда

Перед обработкой записей:

1. **Фокус недели:** `goals/3-weekly.md` → ONE Big Thing.
2. **Приоритеты месяца:** `goals/2-monthly.md` → 2-3 пункта.
3. **Цели года:** `goals/1-yearly-YYYY.md` (текущий год) или `goals/1-yearly.md`.
4. **Видение:** `goals/0-vision-3y.md`, только если запись про долгосрочное направление.

Файлы создаёт онбординг. Их содержимое может лежать в блоке
`<!-- onboarding:begin -->` … `<!-- onboarding:end -->`: читай его как обычный
текст, но правь только вне блока (см. ниже).

## Как найти нужное в файлах

Файлы пишутся свободным текстом, поэтому ищи по смыслу, а не по точному
формату. Типичные варианты:

### 3-weekly.md: ONE Big Thing
```markdown
## Неделя 2026-W11: главный результат

Согласовать бюджет Проекта А на второй квартал
```
или
```markdown
> **Если больше ничего не успею, я:**
> согласую бюджет Проекта А
```
Если фокус не найден: «Не задан, обновите goals/3-weekly.md».

### 2-monthly.md: приоритеты месяца
```markdown
## Приоритеты на 03.2026

Запустить пилот Проекта А с двумя клиентами
Закрыть две вакансии в отделе
```

### 1-yearly: цели года
Список или таблица:
```markdown
| Цель | Прогресс | Статус |
|------|----------|--------|
| Проект А приносит стабильную выручку | 30% | 🟡 |
```
Если прогресса в процентах нет, не выдумывай его: показывай активность
(есть ли задачи и заметки по цели за 7 дней).

## Сопоставление задачи с целями

1. **Связана с ONE Big Thing?** Да → в задаче `→ фокус недели`.
2. **С приоритетом месяца?** Да → `→ месяц: {пункт}`.
3. **С целью года?** Да → `→ год: {цель}`.
4. Иначе операционная задача.

## Повышение приоритета

| Связь | По умолчанию | Повысить до |
|-------|--------------|-------------|
| ONE Big Thing | p3 | p2 |
| Приоритет месяца | p3 | p2-p3 |
| Цель года | p4 | p3 |
| Нет связи | p4 | p4 |

Жёсткий срок всегда p1 независимо от целей.

## Заметки и цели

При сохранении заметки в `thoughts/`:
- если есть подходящая цель, добавь во frontmatter
  `related: ["[[goals/1-yearly#Проект А приносит стабильную выручку]]"]`
  (имя файла бери фактическое);
- добавь тег области: `goal/career`, `goal/health`, `goal/learning` и т.п.

## Активность по целям

- Создана задача или заметка по цели → цель «активна».
- Нет активности 7+ дней → «без движения».
- 14+ дней → «требует внимания».

## Изменение целей

- Владелец явно попросил поменять цель → правь файл `goals/` сразу и покажи
  изменение в отчёте.
- Цель в блоке онбординга → предложи владельцу обновить раздел «Цели» через
  /onboarding, либо (если он просит сделать самому) допиши актуальную
  формулировку ниже блока с датой и пометкой «заменяет пункт выше».
- Сам агент цели не меняет: если запись намекает на смену фокуса, спроси в
  разделе «Требует внимания».

## Раздел отчёта

```html
<b>📈 Прогресс по целям:</b>
• {цель}: {прогресс или «активна»} {emoji}

<b>⚠️ Требует внимания:</b>
• Цель «{цель}» без движения {N} дней
```

## Пример

Запись: «Нужно подготовить презентацию бюджета для руководителя»

Проверка:
- ONE Big Thing «Согласовать бюджет Проекта А» → связана
- Месяц «Запустить пилот Проекта А» → связана

Результат:
```
- [ ] Собрать черновик слайдов с бюджетом Проекта А для руководителя (due: 2026-03-13, p2) → фокус недели
```
