# Этап 3: REFLECT

Записать журнал, обновить память и handoff, собрать HTML-отчёт.

## Вход

- Результаты этапов 1 и 2 (или `.session/capture.json`, `.session/execute.json`)
- `MEMORY.md`
- `.session/handoff.md`
- `.graph/health-history.json` (если есть): динамика здоровья vault

## Задача

Порядок важен: сначала файлы, потом отчёт.

### 1. Журнал действий в daily

Допиши в `daily/{DATE}.md`:

```markdown
## HH:MM [text]
Обработка записей дня

**Создано задач:** N
- [ ] Текст задачи (due: YYYY-MM-DD, p2)

**Сохранено заметок:** M
- [[path/to/thought|Заголовок]]

**Обновлены проекты:** K
- [[projects/{slug}/status|Название]]: что изменилось
```

### 2. Эволюция MEMORY.md

Проверь, есть ли сегодня что-то для долговременной памяти (правила в `SKILL.md`):
- новые ключевые решения;
- существенные изменения в проектах;
- явно высказанные устойчивые предпочтения;
- смена фокуса недели или месяца.

Правила:
- новое заменяет устаревшее, дубликаты не добавлять;
- только значимое и подтверждённое владельцем;
- блок между `<!-- onboarding:begin -->` и `<!-- onboarding:end -->` не
  редактировать: его перезаписывает онбординг. Если там устарело, добавь
  пункт в «Требует внимания» с предложением обновить раздел через /onboarding.

### 3. Наблюдения

Если при обработке были сбои или заметные паттерны, допиши в
`.session/handoff.md` под `## Observations`:

```markdown
- [friction] 2026-03-12: две голосовые записи пришли без текста
- [pattern] 2026-03-12: записи дня только утренние, вечером пусто
```

### 4. Обновить handoff.md

- Последняя сессия: что обработано
- Ключевые решения: если были
- В процессе: незавершённое
- Следующие шаги

### 5. Собрать HTML-отчёт

Шаблон в `SKILL.md`, полная спецификация в `references/report-template.md`.
Включи:

- ONE Big Thing
- Сохранённые заметки и созданные задачи
- Обновлённые проекты
- Загрузку на неделю
- Что требует внимания (просрочки, цели без движения, вопросы владельцу,
  незаполненный онбординг)
- Топ-3 приоритета
- Здоровье vault (если есть `health-history.json`)
- Изменения памяти и наблюдения (если есть)

Раздел здоровья vault:

```html
<b>🩺 Здоровье vault:</b> {score}/100
Без связей: {N} | Битые ссылки: {M} | Связей в среднем: {X} | С описанием: {Y}%
```

## Формат результата

Сырой HTML (без Markdown и блоков кода), уходит прямо в Telegram:
- только `<b>`, `<i>`, `<u>`, `<s>`, `<code>`, `<pre>`, `<a>`;
- никаких `<div>`, `<br>`, `<table>`, Markdown;
- не больше 4096 символов;
- первая строка `📊 <b>Обработка за {DATE}</b>`.

## КРИТИЧНО

- Результат только сырой HTML.
- Все теги закрыты.
- Файлы записаны до отчёта.
