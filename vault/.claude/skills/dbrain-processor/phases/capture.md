# Этап 1: CAPTURE

Прочитать контекст и записи дня, классифицировать их, выдать структурированный JSON.

## Вход

- `daily/{DATE}.md`: записи дня
- `personal/about.md`: профиль владельца (роль, часовой пояс)
- `projects/_index.md`: активные проекты и ключевые люди
- `MEMORY.md`: предпочтения и фильтры решений
- `goals/3-weekly.md`: фокус недели
- `goals/2-monthly.md`: приоритеты месяца
- `goals/1-yearly-YYYY.md` или `goals/1-yearly.md`: цели года

Отсутствующие файлы пропусти и отметь в `context_gaps`.

## Задача

1. Собери словарь проектов и людей из `projects/_index.md` и папок
   `projects/*/` (см. `references/about.md`).
2. Прочитай `daily/{DATE}.md`.
3. Для каждой записи (`## HH:MM [type]`) определи класс:
   - **task**: действие, которое нужно сделать → станет задачей
   - **idea** → `thoughts/ideas/`
   - **reflection** → `thoughts/reflections/`
   - **learning** → `thoughts/learnings/`
   - **project** → `thoughts/projects/` или обновление `projects/{slug}/`
   - **skip**: уже обработано (`<!-- ✓ processed`) или ничего полезного
4. Найди упоминания проектов и людей из словаря.
5. Сопоставь с целями: какую цель запись двигает.

## Формат результата

## Правила классификации

### Признаки задачи
- «нужно», «надо», «сделать», «позвонить», «отправить», «подготовить», «не забыть»
- Срок: «завтра», «в пятницу», «до конца недели», конкретная дата
- Обещание кому-то или follow-up

### Признаки заметки
- Вывод, наблюдение, закономерность: «понял, что», «заметил», «интересно, что»
- Нет явного действия

### Процесс вместо результата
- НЕПРАВИЛЬНО: «Запустить Проект А»
- ПРАВИЛЬНО: «Согласовать с подрядчиком дату запуска Проекта А»

### Заголовок заметки как утверждение
- НЕПРАВИЛЬНО: «Недельный обзор» (ярлык темы)
- ПРАВИЛЬНО: «Недельный обзор быстрее начинать с календаря» (конкретное утверждение)
- Проверка: фраза «Поскольку [[заголовок]], …» читается естественно.

## Важно

- Записи с `<!-- ✓ processed -->` всегда `skip`.
- Сроки переводи в конкретные даты с учётом часового пояса владельца.
- Не приписывай запись проекту, которого нет в словаре: оставь `entities` пустым.
